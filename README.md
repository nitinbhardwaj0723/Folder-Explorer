# Folder Explorer

A simple file browser application developed using C# Windows Forms (.NET Framework 4.8).

## Features

- Displays available drives and folders using TreeView.
- Expand folders to view subfolders.
- Shows files and folders in ListView.
- Displays Name, Size, and Date Modified.
- Shows folder size as `<DIR>`.
- Automatically loads folder contents when selected.
- Handles restricted folder access.

## Technologies Used

- C#
- Windows Forms
- .NET Framework 4.8
- Visual Studio
